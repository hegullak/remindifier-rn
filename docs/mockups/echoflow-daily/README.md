# echoflow Daily mockups

These are early product-direction mockups for the new echoflow opening flow:

1. **Brief** as the home/opening screen
2. **Dagen min** as the second menu item with the actual schedule
3. **Kveldslanding** as the evening wind-down for tomorrow

The split is intentional:

- **Brief** interprets the day: load, rhythm, energy windows, and important highlights.
- **Dagen min** shows the concrete timeline for today plus important personal appointments later this week.
- **Kveldslanding** prepares the user mentally for tomorrow without dragging in the full week.

## Files

- `01-brief-home.svg` — Morning brief / opening screen
- `02-dagen-min.svg` — My day / concrete schedule
- `03-evening-brief.svg` — Evening wind-down

## Product principle

Calendar shows time. echoflow explains the day.

The UI should feel calm, practical and slightly personal, not like another work calendar or productivity dashboard.
